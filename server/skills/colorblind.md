- Red-green (most common) is usually deuteranopia; use the colorblind block with that type. Use scope "media" for charts, images and video; scope "page" when meaning is carried by CSS colors across the page.
- Color alone should not carry meaning: where status or categories are only shown by color, add text or patterns with CSS (e.g. border styles) or aria labels.
- Check charts and legends after applying; take a screenshot to confirm the categories are distinguishable.
